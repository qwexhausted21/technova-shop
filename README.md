# 🛒 TechNova - E-commerce Multi-page Layout

Многостраничный сайт интернет-магазина электроники. Проект демонстрирует навыки связывания страниц, работу с корзиной на JavaScript и адаптивную верстку карточек товаров.

## 🔥 Особенности проекта

*   **Многостраничная навигация:** Связанные между собой страницы (Главная, Каталог, Карточка товара).
*   **Имитация корзины:** Счетчик товаров в шапке сайта. При добавлении товара данные сохраняются в `LocalStorage`, поэтому при переходе между страницами товары не теряются.
*   **CSS Grid:** Идеально ровная сетка товаров, которая подстраивается под ширину экрана (от 4 в ряд на ПК до 1 на смартфоне).
*   **Sticky Header:** Шапка сайта с навигацией всегда остается на виду при скролле.
*   **Современный UI:** Карточки с мягкими тенями, плавными hover-эффектами и скругленными углами.

## 🛠 Технологии
*   HTML5
*   CSS3 (Grid, Flexbox, Custom Properties)
*   Vanilla JavaScript (LocalStorage API, DOM Events)

## 🚀 Как запустить
Проект не требует сборки. Откройте `index.html` в браузере. 
Вы можете кликнуть на карточку товара (чтобы перейти на страницу товара) или нажать «В корзину» (чтобы увидеть, как работает счетчик).
